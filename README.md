# 🚚 DeliveryS

A 3D delivery game developed with Unity where players pick up packages and deliver them across the city.

## Download

➡️ **[Download Latest Build](https://github.com/HoangAnhPeas/DeliveryS/releases/latest)**

## Features

* 📦 Package delivery system
* 🌤️ Day & night cycle
* ⚙️ Audio & graphics settings
* ⏸️ Pause menu
* 🚗 Open city environment
